Grupo 0 · infra de tema

Um mecanismo, três estados

Sem atributo, o app segue o sistema. data-theme="light|dark" no <html> vence a mídia. A API @include light { } continua igual nos componentes.

Tokens viram variáveis

Mesmos nomes Sass, valor novo. Gerado de dois mapas que só citam primitivos existentes.

$color-text: var(--color-text);
$surface:    var(--color-surface);
$color-accent: var(--color-accent); // novo

:root            { @include theme-vars(dark); }
@include theme-root(light) {
  @include theme-vars(light);
}

Mixin light reescrito

:where() zera a especificidade do prefixo: o override vence só por ordem de fonte, como o @media fazia.

@mixin light {
  @media (prefers-color-scheme: light) {
    :where(:root:not([data-theme='dark'])) &
      { @content; }
  }
  :where(:root[data-theme='light']) &
    { @content; }
}

Sem flash, sem herança no embed

Script no <head> aplica a escolha salva em ifdb-theme antes da hidratação. O iframe do fórum tem localStorage particionado: o embed segue o sistema e aceita ?tema=claro|escuro.
